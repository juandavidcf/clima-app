# 🌦️ App del Clima

Aplicación web desarrollada con Flask que permite consultar el clima en tiempo real.

## 🚀 Tecnologías

* Python
* Flask
* Bootstrap
* OpenWeather API

## ▶️ Cómo ejecutar

pip install -r requirements.txt
python app.py

Abrir en navegador:
http://127.0.0.1:5000/
